# SaW

**SaVM WASM Emscripten Runtime** is a project that aims to bring a build of SaVM Nano for the wasm web.

This is a part of the SaVM Monorepo that is **NOT** compiled with official SaVM Releases

## Building

The monorepo https://github.com/savmlang/sa has to be cloned instead of https://github.com/savmlang/saw to compile this runtimes.
